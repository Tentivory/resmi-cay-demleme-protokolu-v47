# RESMİ ÇAY DEMLEME PROTOKOLÜ v47

> Bu belge, Çay İçme ve Demleme İdaresi (ÇİDİ) tarafından 47. kez güncellenmiş, onaylanmış, mühürlenmiş ve sonra unutulmuştur.

## Amaç

Çayı demlemek. Sadece çayı demlemek. Başka hiçbir şey değil. Ama resmi olarak.

Bu yazılım, bir bardak çayı **uluslararası düzeyde** demlemenizi sağlar. Yerel, amatör, ev tipi demleme yöntemleri kesinlikle yasaktır.

## Kurulum

```bash
python3 protokol.py
```

Python 3.8+ gerekir. Çay yaprağı, su ve sabır sizin sorumluluğunuzdadır. Yazılım yalnızca **protokolü** uygular.

## Kullanım

Programı çalıştırın. Ekranı izleyin. Konuşmayın. Çayı bekleyin. Protokol konuşur.

## Uyarılar

- Demleme süresi protokole aykırı kısaltılamaz.
- Şeker miktarı bu sürümde henüz standartlaştırılmamıştır (bkz. v48, beklenen tarih: belirsiz).
